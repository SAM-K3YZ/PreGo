# PREGO Mobile

The mobile frontend for **PREGO**, an antenatal management application.

PREGO is built with React Native, Expo, and TypeScript and communicates with the PREGO backend API.

## Tech Stack

- React Native
- Expo
- TypeScript
- Expo Router
- Zustand
- TanStack Query

## Getting Started

### Prerequisites

Install Node.js and npm before setting up the project.

The application also requires access to the PREGO backend, either running locally or deployed to a development environment.
