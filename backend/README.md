# PREGO Backend

Backend API for **PREGO**, an antenatal management application.

The API is built with Node.js, Express, TypeScript, and MongoDB using Mongoose. It provides the server-side foundation for authentication, patient data, antenatal services, and other PREGO application features.

## Tech Stack

- Node.js
- Express
- TypeScript
- MongoDB
- Mongoose
- Zod
- Redis
- JWT authentication

## Getting Started

### Prerequisites

Make sure you have Node.js, npm, MongoDB access, and Docker installed.
